# 开发与部署

## 本地运行

推荐 Node.js 24，最低 22.12。

安装依赖：

```bash
npm ci
```

启动开发服务器：

```bash
npm run dev
```

访问 `http://127.0.0.1:5173/`。Windows 可运行 `scripts/start-server.cmd`。新版由 Vite 构建，直接双击源码中的 `index.html` 无法正常运行。

## 构建静态网站

```bash
npm run build
```

产物在 `dist/`，可以部署到 GitHub Pages、Netlify、Vercel 或自己的静态服务器。程序使用相对资源路径和 hash 路由，支持仓库子路径。

本地查看生产构建：

```bash
npm run preview
```

默认访问 `http://127.0.0.1:4173/`。预览命令用于本地检查，不是长期运行的生产服务。

## GitHub Pages

仓库已有 [发布工作流](../.github/workflows/pages.yml)：推送 `main` 或手动触发后，安装依赖、运行已有测试、构建 `dist/` 并发布。

**当前仓库仍沿用旧版分支发布方式。** 发布新版前，需要在 GitHub 仓库的 Settings → Pages 中，把 Source 改为 **GitHub Actions**。不要直接发布源码根目录；源码中的 TypeScript 模块需要先构建。

Pages 地址继续使用：

<https://noechou.github.io/coc-investigator-generator/>

切换发布方式不应改变站点地址。角色存储与浏览器、网站来源有关；换域名或端口后不会自动读取原站点数据，请先导出备份。

## 检查命令

运行已有规则、存储与 AI 模拟测试：

```bash
npm test
```

类型检查：

```bash
npm run typecheck
```

生产构建也包含类型检查。当前测试覆盖年龄边界、预算、奖惩骰、旧卡迁移、备份、事务冲突，以及 AI 的格式错误、超时和取消；真实供应商调用与模型可用性仍需密钥联调。

界面仍在迭代，按当前协作约定只做必要前端检查，不因样式调整扩展测试范围。

| `src/features/` | 档案库、建卡、编辑、跑团和打印页面 |

生成原图位于本地 `art-source/`，不进入 git 或站点构建。截图使用虚构示例数据，无真实密钥。

## 修改时保留的约定

- 角色数据版本为 4，旧版 `version: 3` 文件通过迁移层导入；导出与恢复不可静默裁剪内容。
- 职业预算、技能总值、武器成功率和衍生值从共同规则读取，避免存储多份可漂移的副本。
- 初始值与跑团当前值分开。编辑属性不能恢复已消耗的资源，成长不应改变初始点数预算。
- 真实持久化完成后才显示已保存。保存失败时保留页面内修改，允许导出；多标签页写入需检查版本。
- AI 在独立草稿里生成，确认后写入角色；密钥不持久化、不进入日志和导出。
- 关闭或跳过动效不应影响生成数据；支持系统“减少动态效果”。打印保持白纸可读。

## 旧版迁移边界

同源旧键为 `coc7-investigator-sheet-v1`。读取和迁移不得删除它，也不得重新执行年龄修正。旧当前／原始数值、自定义技能、成长和长文本需要保留；无法直接映射的数值写入说明供玩家核对。

导入同 ID 角色默认另存副本，只有玩家主动选择整卡替换才覆盖。导入批次先完整验证，再用事务写入，失败时回滚。
