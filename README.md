# 调查员档案

COC 7 版的建卡与个人跑团工具。支持本地多角色档案、AI 人设生成、规则掷骰、手动编辑、技能检定、状态记录和打印。纸质调查档案与深色工作台可随时切换，电脑、手机均可使用。

新版仍然是静态网站，没有账号、云端存档或作者的 AI 后台。档案写入当前浏览器，电脑和手机通过 JSON 文件转移。

## 开始使用

1. 新建调查员，选择 AI 人设、规则掷骰或手动建卡。
2. 在草稿中检查身份、属性、职业技能和背景，修改会自动保存。
3. 完成建卡后打开跑团页，点击技能或属性即可检定；生命、魔法、理智、幸运由玩家明确调整。
4. 定期导出单卡或备份整个档案库。不要只依赖浏览器缓存。

没有 API 密钥也能使用全部手动、随机和跑团功能。首页可以创建一份明确标注的示例角色。

## AI 服务

在“AI 服务设置”填写自己的密钥。提供 DeepSeek 预设，也可填写兼容 Chat Completions 的 HTTPS 服务地址和模型名。支持根地址、`/v1` 地址和完整的 `/chat/completions` 地址，本机服务可使用 localhost HTTP。

AI 根据人物概念提出属性、职业、技能和背景，程序计算年龄修正、点数预算与衍生值。结果首先保存为草稿；AI 属性标记为“人设生成”，不冒充随机骰点。可以取消、重试或单独重写背景，现有角色不会被运行中的请求逐步覆盖。

密钥只保留在当前页面会话中，不写入角色、浏览器持久设置、日志或导出文件。非密钥的服务地址和模型偏好会记住。刷新页面后须重新输入密钥。

自定义服务必须允许浏览器直连。认证、限流、跨域、超时或格式错误会明确提示；网站没有公共转发服务。默认模型可以编辑，实际可用性由服务提供方决定。

**真实 AI 联调尚未完成**：代码已通过模拟请求测试，未使用真实密钥调用供应商。不能据此保证所有自定义服务的模型参数和跨域配置都可用。

## 存档与旧版迁移

- 档案保存在 IndexedDB，多角色独立保存。只有事务完成后才显示已保存。
- 旧版 `version: 3` JSON 可以导入。同源发现旧 `coc7-investigator-sheet-v1` 存档时提供迁移入口，不删除旧数据。
- 当前资源、成长点、自定义技能、空装备、长文本与头像会尽量无损保留。旧版手填派生值和不一致数据会保留说明，不重新掷年龄修正。
- 不同浏览器、不同域名或端口的存储互不相通，需要文件导出导入。
- 同一角色已存在时默认另存副本；明确选择整卡替换才覆盖。不会自动合并两台设备各自的修改。
- 导入先验证完整文件，损坏或超过容量的文件会报错，不静默截短文字。单次最多导入 200 份档案。

## 运行与构建

需要 Node.js 22.12+ 或 Node.js 24。

安装依赖：

```bash
npm ci
```

开发预览：

```bash
npm run dev
```

默认访问 `http://127.0.0.1:5173/`。旧版直接双击 HTML 的运行方式不适用于新版源码。

生成静态网站：

```bash
npm run build
```

构建结果在 `dist/`。可以把该目录部署到 GitHub Pages、Netlify、Vercel 或自己的静态服务器。Vite 使用相对资源路径，页面使用 hash 路由，适配 GitHub Pages 的仓库子路径。

本地查看构建结果：

```bash
npm run preview
```

Windows 可以运行 `scripts/start-server.cmd`，它会启动开发服务器。

## 项目结构

- `src/domain/`：角色结构、规则目录、预算、检定与数据验证。
- `src/storage/`：本地数据库、导入导出和旧卡迁移。
- `src/ai/`：模型请求、生成草稿和背景重写。
- `src/features/`：档案库、建卡、编辑、跑团与打印。
- `src/styles/`：双主题、响应式布局和打印样式。
- `public/art/`：原创生成的街景、调查桌与可选档案肖像，见 [素材说明](public/art/ASSETS.md)。系统开启“减少动态效果”时会关闭界面动效。
- `legacy/`：旧版静态实现，仅供核对和迁移参考，不作为新版入口。

## 规则与限制

本项目不是完整的多人跑团平台。首版不提供云同步、房间、地图战棋、战斗自动裁定或守秘人团务管理。检定不会自动扣除资源，重掷、幸运消费及其他裁定由玩家和守秘人决定。

7 版年龄修正中，20–39 岁进行一次 EDU 增强，40–49 岁两次，50–59 岁三次，60 岁起四次。初始技能上限默认 75，可按团内规则调整；成长点与初始点数分开记录。具体规则以正式规则书与守秘人裁定为准。

本项目为非官方玩家辅助工具，与 Chaosium 无关联。许可证为 MIT，见 [LICENSE](LICENSE)。
